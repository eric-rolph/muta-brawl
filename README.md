# Muta-Brawl

Browser-based creature genetics, breeding, scavenging, and arena betting game built with vanilla HTML, CSS, and JavaScript.

## Gameplay Loop
- **Scavenge (`map`)**: Gather elemental and biological genetic material.
- **Gene Lab (`lab`)**: Splice, mutate, and breed fighters (`genetics.js`).
- **The Pit (`arena`)**: Pit creatures against each other and wager from your bankroll (`combat.js`, `economy.js`).

## Local Development
Open `index.html` directly or serve the repository root with any static HTTP server:

```bash
python -m http.server 8000
```
